# Build Week reviewer guide

The canonical interactive guide is available at `/reviewers` in the application.

## Fast test path

1. Open `/journey`; complete the current move, save an energy score, write a fictional reflection, and ask the GPT-5.6 coach a practical question.
2. Open `/studio`; inspect aggregate progress and support signals. Verify that no journal or coach text appears.
3. Open `/guide#first-days`; preview the nine enhanced Days 1–3 capsules for a People Manager staying in the same company and city.
4. Use **Reset demo** to restore fictional web state.
5. Open [@first90_OpenAI_Week_bot](https://t.me/first90_OpenAI_Week_bot) privately, send `/start`, complete the six-question onboarding, and try `/today`.
6. Add the bot to a Telegram test group and try `/admin`, `/metrics`, `/roles`, `/preview 1`, and `/privacy`.

## Supported scope

- Content-ready role: **People Manager**.
- Journey depth: 90 days, three touchpoints per day, 270 universal capsules.
- Enhanced content: nine Days 1–3 capsules for same-company, same-city transitions.
- Contexts: same/new company, same/new city, office/hybrid/remote work.
- Cities: 16 fictional European examples with IANA time zones.

## Deliberate boundaries

- Phase 1 is free; there is no payment gateway or billing data.
- Team Studio is read-only in the Build Week release.
- The public web journey uses resettable fictional data.
- A personal Telegram subscription remains in Telegram for this release.
- Only People Manager has a complete reviewed journey.
