04
CONTENT-READY SCOPE

One role, complete depth

People Manager is the content-ready role in this release: 90 days and 270 universal touchpoints. Personalization supports same or new company, same or new city, and office, hybrid, or remote work.

Days 1–3 also have enhanced content for an internal manager staying in the same city. Sixteen seeded European cities provide valid IANA time zones for delivery.

Additional roles are a content-expansion track, not simulated coverage.

05
HONEST DEMO BOUNDARIES

What is deliberately not in Phase 1

  • No payment gateway: early access is free; secure hosted checkout belongs to Phase 2.
  • No self-service content editor: Build Week content is versioned in code and Studio is read-only.
  • The public web participant is fictional and resettable; a personal Telegram subscription stays in Telegram.
  • Without an OpenAI API key, the coach uses a clearly labeled deterministic fallback.
  • Only People Manager has a complete reviewed journey today.
